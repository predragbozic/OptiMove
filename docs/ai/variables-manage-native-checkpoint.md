# Variables Manage native create and version checkpoint

Local preparation on the v112 bridge. This checkpoint adds native club
authorization for creating a canonical variable and adding a semantic
version. It keeps the checked Roles registry closed and carries no official
migration. Test grant staging belongs exclusively to a disposable database.

The native actor needs the staged SQL word, the active club workspace and
legacy club admin holding, an active session, Variables View and Variables
Manage at that club. Preserve the existing target ownership, formula inputs,
pinned and activation constraints, and platform rules. New writes keep the
existing definition/input locks before actor row locks. Existing requests,
uncertain commit confirmation and refreshed responses recheck scope without
recreating effects.

Native J15 Copy to own, Hide and Show again are also covered. Copy keeps
its atomic and bounded active-system mapping inheritance as club drafts,
without independent Mapping writes or activation. Hide and Show again
retain their club preference and existing activation rules. Personal hide
remains separate.

Owned classification domains, categories, icons and links use the same
club-scoped Manage check. Classification reads and the existing link
ownership rules retain their behavior.

P3 reference-table writes follow the same active resource-club rule. Their
existing actor checks precede the shared request lock. The writer checks the
receipt under that lock before calling the sanctioned function. Chart and
Radar widget bindings keep their existing Dashboard authorization.

Native effects and their durable receipts commit with the first-use marker.
No-op, replay, refusal and platform writes leave it untouched. An unconfirmed
commit verifies the durable receipt under fresh authorization. Overlapping
club lifecycle effects prefer the narrow Rename/Archive grant when both
grants apply. Only the narrow grant applies in a team.

The bridge must retain existing Settings grants on the previous server and
keep the full Manage word hidden until all previous instances drain. The
database seed, audit, rollback and old-server rehearsal ship with the bridge.
